# 代码位置体检 —— 目录与文件位置的整理信号

定位:AGENTS.md 体系回答"每个目录的契约是什么";本篇回答"**代码是否住在对的地方**"。位置体检是 audit 的组成部分,全程只读;实际搬移仍走 restructure 门禁(见 [restructure.md](restructure.md) §1)。判定的唯一权威是**项目自身的落点约定**(根篇「代码改动 → 同步更新」映射表、各篇「核心文件导航」与落点链),不是外部审美。

## 第一步:位置清单

先逐目录产出一份清单,作为后续所有"错位"判定的基准:

| 目录 | 职责一句话 | 成员概况(主要文件 / 子目录) |
|---|---|---|

- 职责取自该目录 AGENTS.md / README / 包注释;没有自述时从入口符号归纳,并标注"无自述"。
- 这份清单同时是文档导航表的核对素材:清单与导航表冲突 → 位置信号 7。

## 位置信号目录

信号全部 advisory,单独不构成搬移理由;提案须逐项带正向证据,进入 restructure.md §3 的格式。

| # | 信号 | 判据 | 风险 | 证据来源 |
|---|---|---|---|---|
| 1 | 平铺超载(文件扇出) | 目录直接平铺非测试源文件 >~20 | 中 | splitting.md 同名信号。加权代码量低、父篇提及过,都不取消。提案按 restructure.md §2 重组类聚类 |
| 2 | 根目录/顶层杂物 | 仓库根直接平铺非测试源文件 >10;顶层目录堆积散件源文件、一次性脚本 | 低 | 脚本只报仓库根的数量(恰好 10 个不报),不指定目标目录;去向对照项目既有落点 |
| 3 | 错位文件 | 文件内容域与所在目录职责不符 | 低–高(跨层即高) | 引用共现(`git grep` 入口符号)、命名前缀、git 共变、位置清单比对 |
| 4 | 碎目录/孤儿 | 源文件数 1 且无源子目录、且与同层兄弟不对称的目录;或仅含一个子目录的壳目录 | 中 | 引用者分析:唯一/全部 importer 是谁;构建入口(`main`/`index`/`lib`/`mod`/`__init__` 的文件,以及 Cargo 的 `src/bin/` 目录)不算;兄弟多为单文件属本地惯例,不算不对称 |
| 5 | 兄弟不对称 | 同层兄弟目录内部结构各说各话、命名惯例漂移 | 高(牵动惯例) | 同层清单横向比对;只建议统一方向,不强制 |
| 6 | 测试落点漂移 | 测试不跟随项目既有落点惯例 | 低 | 项目既有惯例是权威,不引入外部惯例;测试与源码永不拆散(restructure.md §6) |
| 7 | 文档位置断言脱节 | AGENTS.md 导航表/映射表里的路径已失效或指向已搬走的文件 | — | 属 sync 职责,体检交叉确认;自检脚本 `--structure` 输出路径断言告警(先剥围栏,路径按「文档相对 → 逐级祖先 → 仓库根,各层兼试 `src/` 前缀」解析,构建产物与 submodule 前缀跳过) |
| 8 | 目录扇出 | 直接有实质内容的子目录 >15,即使这些子目录已经存在 | 中–高(要改导入路径) | splitting.md 同名信号。提案按 restructure.md 分层类,跨树同名优先。把多个子目录塞进少数单元格不算已下钻 |

## 提案格式与分级

复用 restructure.md §3 的表格(文件或子目录 | 目标位置 | 证据 | 风险标注),并标注提案类别:

- **归位类**(信号 2/3/4):单文件即可成提案,不需要 2–8 簇聚类;碎目录合并以引用者分析代替聚类。
- **重组类**(信号 1):按 restructure.md §2 聚类。
- **分层类**(信号 8):已有子目录仍然分组;跨树同名进同一份提案。用户拒绝搬移时报告保持未收敛,不为尚不存在的分组目录建篇。
- 风险分级:同目录内归位 < 跨目录同层 < 跨层/涉公开 API 面。跨层,以及会改掉已发布导入路径的搬移,默认仅提案(restructure.md §5)。

输出提案后**停下等逐目录批准**;批准后由 restructure 阶段执行。audit 与 sync 永不移动代码。

## 判定纪律

- **惯例优先**:项目已有落点约定是唯一权威;与惯例冲突的"更优雅"布局不提案。
- **信号不是阈值**:任一信号只触发评估;给不出正向证据的文件原地不动。
- 一次体检的提案按信号分组列出,批准按目录粒度进行;脚本信号(`--structure`)只是初筛,命名不对称等惯例判断必须由 agent 读代码完成。
